# UK Skilled Worker eligibility (verify before every run)

Rules and rates change at least annually. Re-check both sources below each time; treat the figures here as a starting point, not current truth.

- Eligible occupations: <https://www.gov.uk/government/publications/skilled-worker-visa-eligible-occupations/skilled-worker-visa-eligible-occupations-and-codes>
- Going rates: GOV.UK Appendix Skilled Occupations

## The rule that catches people out

Since **22 July 2025** the Skilled Worker route requires the occupation to be **RQF Level 6+** (degree level), unless it sits on the Temporary Shortage List. Occupations classified *Medium Skilled* are blocked.

Pay must be the **higher of £41,700 or the occupation's going rate**. New-entrant floor is £33,400.

So the general threshold is rarely the operative number — the going rate usually is.

## Why this decides the whole shortlist

The same job codes differently depending on title and seniority:

- *Marketing Executive / Specialist / Associate / Coordinator* → **3554** → cannot be sponsored
- *Marketing Manager / Product Marketing Manager / Head of Growth* → **2432** → can be sponsored
- *Sales Executive / SDR / BDR* → **3552** → cannot be sponsored
- *Business Development Manager / Partnerships Lead* → **3556** → can be sponsored

Filter the shortlist to manager-and-above titles, and tell the person to confirm the intended SOC with the recruiter before investing in a process.

Third-party visa sites often still list 3554 as "eligible" on stale pre-July-2025 data. Trust GOV.UK's skill-level classification over aggregator sites.

## Rough mapping from title to code

- Anything with *partnership / business development / ecosystem / alliances* → 3556
- Anything with *product manager / product owner / head of product* → 2440
- *Director / VP* in a marketing function → 1132 (note the £87,300 rate makes this a stretch)
- Everything else marketing/growth at manager level → 2432

This is a heuristic for ranking. The employer assigns the actual code on the Certificate of Sponsorship.
